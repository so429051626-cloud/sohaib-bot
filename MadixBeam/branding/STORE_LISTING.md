# Madix Beam — Store listing

## English

**App name:** Madix Beam

**Short description (80 characters):**
Scan once, send at Wi-Fi Direct speed. Encrypted. No internet. No account.

**Full description:**

Madix Beam transfers photos, videos, documents and messages between devices at very high
speed. Scan a single QR code and the two devices connect over a direct, encrypted Wi-Fi link:
no internet, no router, no account and no cables.

When no radio may be used at all, Madix Beam can also transfer through animated QR codes
alone, read by the camera in any order with missed frames recovered automatically.

SECURITY
• Device pairing with ephemeral ECDH P-256 key agreement and a six-digit verification code
• AES-256-GCM encryption bound to each transfer
• Optional password protection strengthened with PBKDF2 (200,000 iterations)
• SHA-256 verification of every received file
• App lock with biometrics or the device screen lock
• Screenshot and screen-recording protection
• Private storage excluded from cloud backups

FEATURES
• Any file type: photos, videos, documents, archives and text
• Four speed profiles from Reliable to Turbo, with a live frame-rate control
• Automatic compression and optional photo optimisation that also removes location metadata
• Share directly from any app into Madix Beam
• Save received files to the gallery or the Downloads folder
• Complete transfer history kept only on the device
• Reads ordinary QR codes as well
• Light and dark themes, English and Arabic

Madix Beam collects no personal data and contains no advertising, analytics or tracking.

**Category:** Tools
**Content rating:** Everyone
**Data safety:** No data collected; no data shared. Network access is used only for the direct link between the user's own devices.
