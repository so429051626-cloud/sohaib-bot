# MADIX Convert — محوّل الكشوفات الذكي

صوّر كشف مكتوب بخط اليد ← بيصير جدول Excel أو PDF منسق، وبيطلعلك المكررات برقم الهوية وأرقام الهوية الغلط والبيانات الناقصة.
الصور ما بتنحفظ على السيرفر، والدفع بالصفحة بأكواد مطبوعة زي كروت النت.

## الميزات

### للمستخدم (`index.php`)
- **تصوير الكشف** من الكاميرا أو المعرض (حتى 40 صفحة مرة وحدة).
- **محرر الصورة**: قص بالزوايا مع تصحيح الميلان، وتدوير، وتحسين الوضوح، وعدسة تكبير وقت السحب.
- **ضغط تلقائي للصور** لتناسب النت الضعيف (حوالي 0.5 لـ 1.5 ميجا للصفحة).
- **قراءة بالذكاء الاصطناعي** لخط اليد العربي، وتحويل الأرقام العربية لإنجليزية، وتعليم الخانات غير الواضحة.
- **كشف طويل؟** الصفحات بتكمّل على نفس الأعمدة تلقائياً.
- **فحص رقم الهوية الفلسطيني** (رقم التحقق): بيكشف أي رقم انكتب أو انقرأ غلط.
- **المكررات** بثلاث طرق: برقم الهوية، وتشابه الأسماء (أ/إ/ا، ة/ه، عبد الله/عبدالله…)، ونفس الجوال، مع حذف المكرر بضغطة.
- **الفحص بين الكشوفات**: بيعلّم الأشخاص الموجودين بكشوفات سابقة على الجهاز.
- **محرر بيانات متكامل** داخل التطبيق:
  - تعديل أي خانة مباشرة (Enter للخانة اللي تحتها، وTab للي جنبها).
  - إضافة وحذف الصفوف والأعمدة، وتغيير اسم العمود ونوعه وترتيبه.
  - البحث بالاسم أو رقم الهوية.
  - فرز أبجدي أو رقمي تصاعدي وتنازلي، والرجوع للترتيب الأصلي.
  - تحديد عدة صفوف وتعديلها أو تأكيدها أو حذفها مرة وحدة.
  - نسخ الصفوف ولصقها من وإلى Excel وGoogle Sheets.
  - التراجع والإعادة (Ctrl+Z / Ctrl+Y).
  - ألوان واضحة: المكرر برتقالي، والهوية الغلط أحمر، والناقص أزرق، وغير الواضح أصفر.
  - دمج عدة كشوفات بكشف واحد مع عمود "المصدر".
- **صورة السطر الأصلي** جنب كل صف للمقارنة والتصحيح.
- **التصدير**:
  - Excel حقيقي (xlsx) بأربع أوراق: الكشف، والمكررات، وتدقيق الهويات، وملخص. من اليمين لليسار، مع ألوان وفلاتر وأول سطر مثبت.
  - PDF بدقة عالية (حوالي 216 DPI)، بخط عربي واضح وصفحات A4.
  - CSV، وطباعة، ومشاركة مباشرة (واتساب وغيره).
- **الخصوصية**: الصور بتنحذف تلقائياً بعد التصدير، وبعد مدة بتختارها، والكشوفات محفوظة على الجهاز فقط.
- **المحفظة**: الرصيد بالصفحات، وشحن بكود، وسجل حركات، وأسعار، وطلب كود عبر واتساب.
- **يتثبت كتطبيق (PWA)** على شاشة الجوال، مع شاشة بداية أنيقة، ووضع فاتح وداكن، ويشتغل بدون نت للكشوفات المحفوظة.

### لوحة الإدارة (`admin.php`)
- **نظرة عامة**: المستخدمين، والصفحات المقروءة، والإيرادات، وتكلفة الذكاء الاصطناعي، ورسم آخر 14 يوم، وحالة السيرفر، ونسخة احتياطية.
- **نماذج الذكاء**: أضف أو عدّل أي نموذج Claude، مع سعره، ومستوى التفكير، وتكلفته على المستخدم بالصفحات، والنموذج الافتراضي، وزر اختبار.
- **مفاتيح API**: أكثر من مفتاح، محفوظة مشفّرة، بأولوية وانتقال تلقائي للمفتاح التالي لو واحد فشل أو خلص رصيده، مع اختبار اتصال وآخر خطأ.
- **الأكواد والكروت**: توليد دفعات أكواد (صفحات وسعر)، وطباعة كروت A4 جاهزة للقص، وتصدير CSV، وإيقاف وتفعيل.
- **المستخدمين**: بحث، وتعديل الرصيد، وكلمة سر مؤقتة، وإيقاف، وصلاحية مدير، وسجل حركات.
- **الإعدادات**: اسم التطبيق، والوصف، والتذييل، ورقم واتساب، والأسعار، وهدية التسجيل، وإعلان، ووضع صيانة، وحدود الاستخدام، و**رفع أيقونة التطبيق**.
- **السجلات**: كل عملية قراءة (النموذج، والتوكنز، والتكلفة، والمدة) وكل عمليات الإدارة.

## التشغيل على الاستضافة

### المتطلبات
- PHP 7.4 أو أحدث (8.x أفضل) مع: `pdo_sqlite` و`curl`، و`gd` (اختياري لرفع الأيقونة).
- **HTTPS** (ضروري للكاميرا وتثبيت التطبيق على الجوال).

### الخطوات
1. ارفع مجلد `madix-convert` كامل على الاستضافة، مثلاً `https://example.com/madix-convert/`.
2. تأكد إن السيرفر بيقدر يكتب داخل المجلد. التطبيق بينشئ مجلد `data/` لحاله، وفيه قاعدة البيانات واسمها عشوائي.
3. افتح **`admin.php`** وأنشئ حساب المدير (أول تشغيل).
4. من **مفاتيح API** أضف مفتاحك من [console.anthropic.com](https://console.anthropic.com) ← API Keys، واضغط "حفظ واختبار".
5. من **الأكواد والكروت** ولّد أكواد واطبعها.
6. من **الإعدادات** حط رقم واتساب والأسعار، وارفع أيقونتك إذا بدك.
7. المستخدمين بيفتحوا **`index.php`** وبيسجلوا وبيبدأوا.

### Nginx
ملف `.htaccess` بيحمي المجلدات على Apache. على Nginx أضف:
```nginx
location ~ ^/madix-convert/(app|data)/ { deny all; }
client_max_body_size 12m;
fastcgi_read_timeout 600;
```

### متغيرات اختيارية
| المتغير | الاستخدام |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح API من السيرفر بدل لوحة الإدارة |
| `MADIX_DATA_DIR` | مسار مجلد البيانات (الأفضل يكون خارج public_html) |
| `MADIX_MOCK_AI=1` | **للتجربة فقط**: بيرجع بيانات وهمية بدون ما يتصل بالذكاء الاصطناعي |

## التكلفة والتسعير
- كل صفحة بتنقرأ بطلب واحد للذكاء الاصطناعي. التكلفة الفعلية لكل صفحة بتظهر بلوحة الإدارة (نظرة عامة والسجلات).
- الصفحة ما بتنخصم من رصيد المستخدم إلا إذا انقرأت بنجاح. إعادة قراءة نفس الصورة مجانية خلال 24 ساعة (العدد بيتحدد من الإعدادات).
- المدير ما بينخصم منه شي.

## الخصوصية والأمان
- الصورة بتنبعت للقراءة وبتنحذف فوراً من السيرفر، وما بتنحفظ أبداً.
- الكشوفات والجداول محفوظة على جهاز المستخدم فقط.
- كلمات السر مشفّرة (bcrypt)، ومفاتيح API مشفّرة، وفي حماية CSRF وحد للمحاولات على الدخول والأكواد والقراءة.
- قاعدة البيانات اسمها عشوائي داخل مجلد محمي.
